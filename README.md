# SmartDocs: AI-Powered Document Q&A System

An enterprise-grade Retrieval-Augmented Generation (RAG) backend built with Java and Spring Boot.

## 🎥 Live Demo Video
[Click here to watch the demo](https://drive.google.com/file/d/1t16gV1Sggg-dL07Ep2_TML4gqUzfKAlG/view?usp=sharing)

## 🛠️ Tech Stack
*   **Backend:** Java, Spring Boot
*   **Database:** PostgreSQL with `pgvector`
*   **AI Integration:** LangChain4j, Google Gemini (Embeddings), Groq / Llama 3 (Chat)
*   **PDF Parsing:** Apache PDFBox

## 🚀 Features
*   Upload PDF documents and extract text.
*   Generate 3072-dimensional vector embeddings via Google Gemini.
*   Store vectors in PostgreSQL for high-performance cosine similarity search.
*   Ask questions and get context-aware answers generated by Groq (Llama 3).
*   Includes a basic HTML/JS frontend to demonstrate the REST APIs.
